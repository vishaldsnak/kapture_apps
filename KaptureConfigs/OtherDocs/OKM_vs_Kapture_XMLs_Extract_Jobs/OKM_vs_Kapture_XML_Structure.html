What changed in RMI Export and MNAO Data Export

  • The root element and its attribute changed: CONTENT RECORDID is now content contentid.
  • The header elements come from Kapture, so the OKM date, locale, version and repository elements are not in the export.
  • The channel elements match OKM, apart from the differences marked in each table.
  • DOCUMENTID and CATEGORIES are unchanged.

How to read it

  • "Seen in" counts the documents with that element, against all documents read for that tool. The count covers the exported XML, after each tool's filter.
  • Kapture often leaves out an empty element that OKM always wrote, so a lower Kapture count does not by itself mean lost data.
  • ATTACHMENT appears in both forms in Kapture: a plain file name, or the five child elements shown.
  • Values are written in CDATA in both, so rich text reads as HTML. Kapture dates, flags and ids in the header stay plain, as they did in OKM.
